- Contratos de datos, métricas y semántica de G1–G10 intactos:
  `metrics.frozen.test.ts`, `bucketRenderState`, `parseYearInput`,
  `null≠0`, cobertura/denominador explícito en primera lectura.
- Reduced-motion, teclado, touch y presets de cortina (G10.1) intactos.
- Contraste AA recomputado con la paleta nueva antes de cerrar.

  generan desde las ortofotos ya catalogadas, con cobertura verificada.
- Hooks de test (clases/atributos usados por g8/g10) se conservan o se
  actualizan los scripts — nunca se rompe la suite para que «pase».
