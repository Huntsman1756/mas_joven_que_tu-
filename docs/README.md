# docs/ — índice

Este índice separa dos tipos de documento:

- **A. Documentación para lectores y jurado:** describe el producto, los datos, la metodología y el paquete de entrega tal como están hoy.
- **B. Registros de trabajo:** conservados por trazabilidad. Recogen revisiones, auditorías y decisiones de una fase concreta; pueden contener estados históricos que ya no son vigentes.

Las rutas son relativas a `docs/`.
